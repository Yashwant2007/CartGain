# H.5 — CARTGAIN ACCEPTABLE USE POLICY (AUP)

> **Version:** 2026.08.15 | **Effective:** 2026-08-16
> **Incorporated by reference into ToS §20.**

---

## 1. SCOPE

Applies to all Merchants, team members, API users, and anyone accessing the Platform.

---

## 2. PROHIBITED ACTIVITIES

You shall not use the Platform to:

| Category | Examples |
|---|---|
| **Illegal** | Fraud, phishing, counterfeit goods, regulated products without license, money laundering |
| **Spam/Unsolicited** | Messages without valid consent, purchased lists, cold outreach via WhatsApp/SMS/Email |
| **Deceptive** | Misleading prices, fake discounts, bait-and-switch, impersonation |
| **Harmful** | Malware, ransomware, exploits, vulnerability scanning, DoS |
| **IP Infringement** | Unauthorized use of trademarks, copyrights, trade secrets |
| **Platform Abuse** | Scraping, automated account creation, credential stuffing, API rate limit evasion, reverse engineering |
| **Data Misuse** | Exporting Customer data for unrelated purposes, sharing with unauthorized parties, violating DPA |
| **AI Misuse** | Prompt injection, extracting system prompts, generating harmful/illegal content via AI Bargain |
| **Regulatory Violations** | TCPA, TRAI/DLT, Meta Policy, CAN-SPAM, CASL, PECR, GDPR, DPDP violations |

---

## 3. MESSAGING-SPECIFIC RULES

- **WhatsApp:** Only approved templates; 24-hr care window; explicit opt-in; honor STOP; no promotional in utility templates.
- **SMS (India):** DLT-registered header/template; NCPR scrubbing; consent artifacts; 6-char sender ID.
- **SMS (US):** TCPA prior express written consent; STOP honor; no autodialer to wireless without consent.
- **Email:** CAN-SPAM header (physical address, unsubscribe); CASL consent (implied/express); PECR soft opt-in limits.
- **Frequency:** Respect Platform defaults (max 3 messages/cart, 24-hr gaps). Do not circumvent.

---

## 4. AI BARGAIN RULES

- Floor price ≥ cost + minimum margin.
- No false scarcity, fake deadlines, unauthorized promises.
- Auto-accept disabled by default; enable only with review process.
- Monitor conversations; intervene if AI hallucinates.

---

## 5. ENFORCEMENT

| Violation | Action |
|---|---|
| Minor/First | Written warning, 7-day cure |
| Repeated/Serious | Suspension (immediate), investigation |
| Egregious/Illegal | Termination (immediate), law enforcement referral |
| Platform Risk (spam complaints, blocklisting) | Emergency suspension (no notice), appeal within 48 hrs |

**No Refund** for suspension/termination due to AUP violation.
